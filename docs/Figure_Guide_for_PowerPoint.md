## FIGURE EXTRACTION INSTRUCTIONS

### For HTML Files:
1. Open HTML file in web browser (Chrome, Safari, Firefox)
2. Navigate to the relevant section
3. Right-click on figure → "Save image as..." OR
4. Use browser screenshot tool (Cmd+Shift+4 on Mac)
5. For tables: Right-click → "Inspect" → Copy HTML or screenshot

### For PDFs:
1. Open PDF in Preview (Mac) or Adobe Reader
2. Navigate to figure
3. Use selection tool to select figure
4. Copy (Cmd+C) and paste into PowerPoint OR
5. Export as image (File → Export → PNG/JPEG)

### Creating New Figures:
- Use PowerPoint's built-in chart tools
- Use online tools like BioRender for trial schematics
- Use R/Python if you have the data

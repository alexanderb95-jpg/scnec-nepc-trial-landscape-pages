## Key Notes:
- **FDA Status**: Sacituzumab govitecan indication was withdrawn by FDA on November 2, 2024, but remains recommended by some guidelines
- **Trial Phases**: All trials listed are registrational (Phase 2/3) trials that led to FDA approvals
- **Toxicity Grading**: TRAEs reported using CTCAE grading system
- **Population Definitions**: 
  - Locally advanced: T4b, N1-3, M0
  - Metastatic: M1 disease
- **Treatment Lines**: Trials span first-line through third-line+ settings

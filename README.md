# R Project Directory

This directory contains R scripts, analyses, and related files for research projects.

## Directory Structure

```
R/
├── scripts/          # R scripts (.R files)
├── rmarkdown/        # R Markdown files (.Rmd files)
├── data/             # Data files (.csv, .xlsx, .rds, .json)
├── outputs/          # Generated HTML outputs from R Markdown
├── figures/          # Generated plots and images (.png, .svg, .eps, etc.)
├── documents/        # PDFs, Word documents, PowerPoint files, text files
├── python/           # Python scripts (.py files)
├── docs/             # Documentation and markdown files (.md)
├── temp/             # Temporary files (backups, temp Excel files, etc.)
├── cache/            # R Markdown cache directories
└── figure/           # Additional figure directories (if any)
```

## File Organization

- **scripts/**: All standalone R scripts for data analysis
- **rmarkdown/**: R Markdown files for generating reports
- **data/**: Raw and processed data files (CSV, Excel, RDS)
- **outputs/**: HTML reports generated from R Markdown (regenerated on knit)
- **figures/**: Generated plots and visualizations (regenerated from scripts)
- **documents/**: PDFs, Word documents, PowerPoint presentations, text files
- **python/**: Python utility scripts
- **docs/**: Documentation, guides, and markdown files
- **temp/**: Temporary files that can be safely deleted

## Git Configuration

The `.gitignore` file is configured to:
- Ignore R workspace files (`.RData`, `.Rhistory`)
- Ignore generated outputs (HTML, PDFs, plots)
- Ignore temporary files and cache directories
- Track source code (R scripts, R Markdown files)
- Optionally track or ignore data files (currently configured to track)

## Usage Notes

- **Outputs and figures are regenerated**: HTML outputs and figures are typically regenerated by running R Markdown files or scripts, so they are ignored by git
- **Data files**: Currently tracked in git. If data files become large or sensitive, uncomment the relevant lines in `.gitignore`
- **Temporary files**: Files in `temp/` are ignored by git and can be safely deleted

## Getting Started

1. R scripts are in `scripts/` directory
2. R Markdown reports are in `rmarkdown/` directory
3. Data files should be placed in `data/` directory
4. Generated outputs will appear in `outputs/` and `figures/` directories
